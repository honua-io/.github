# Contributing

**Honua repositories do not accept code contributions from outside Honua Geo Inc.**
This applies to every repository in the honua-io organization, whatever its license.
Pull requests from outside the organization are closed automatically.

What is welcome:

- **Bug reports and feature requests** as GitHub issues in the repository concerned.
  Use the issue templates.
- **Security findings** through the [security policy](SECURITY.md). Do not open public
  issues for suspected vulnerabilities.
- **Interoperability reports** from client tooling as issues, with the request and
  response that misbehaved.
- **Questions and design feedback** on the open standards as issues in
  [geospatial-mcp](https://github.com/honua-io/geospatial-mcp) and
  [geospatial-grpc](https://github.com/honua-io/geospatial-grpc).

If you have a patch, describe the fix in an issue and we will implement it. Apache-2.0
repositories may be forked under their license.
